Create a simple, clear SVG visual cue that will be projected onto an assembly
workbench by a small DLP projector.

Cue type: $cue_type
Headline: $headline
Message: $message

Requirements for a CLEAR and READABLE projected cue:
1. Use viewBox="0 0 800 600" and keep all content within a 700x500 area,
   at least 50 px from every edge.
2. Black background with high-contrast elements.
3. Exactly ONE warning symbol (!) at the top.
4. Text structure (maximum two levels):
   - Headline below the symbol: $headline_color, font-size="36", bold.
   - Condensed message (maximum 3 short lines) inside a yellow block below the
     headline, black text, font-size="28", bold.
5. Use text-anchor="middle" for centred text and break long text into shorter lines.
6. Keep at least 25 px spacing between elements; no element may overlap another.

SVG structure:
- Start with <?xml version="1.0" encoding="UTF-8"?>
- Then <svg xmlns="http://www.w3.org/2000/svg" viewBox="0 0 800 600">
- Add a black background: <rect width="100%" height="100%" fill="black"/>
- End with </svg>

Provide ONLY the SVG code. No explanations, no Markdown.
